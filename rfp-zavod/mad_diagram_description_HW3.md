5-я Задача

Система представляет собой программу для проверки статистических гипотез о принадлежности заданных экспериментальных данных некому теоретическому распределению.

Такой вывод напрашивается из подразделения на модуль `Experiment` и `Criterion`, в которых:

### Criterion
- представлены абстракции различных тестовых статистик
- происходит подсчет критических значений статистик 

### Experiment
- присутствует большой модуль для конфигурации работы эксперимента, где можно задать его тип, проверяемую гипотезу и какой критерий попытаться применить 
- есть фабрика для сборки эксперимента по заданным настройкам 
- есть набор структур для контроля за ходом эксперимента и генерации репортов 
- отдельный модуль, заведующий генерацией случайных чисел
- модуль для менеджмента workers
